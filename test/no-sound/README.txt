Based on the SHOGUN board game designed by Teruo Matsumoto,
(c) 1976 Epoch Co. Ltd (Epoch Playthings in the US; Ravensburger in Europe from 1979).
One Game A Month entry, September 2013.
PC / web edition 1.2 (2026), built from the Android v1.11 game.

HOW TO PLAY
Capture the enemy SHOGUN, or leave him with only his SHOGUN and one pawn.
The hidden terrain under each piece sets how far it moves: exactly 1-4 squares
for a pawn, 1 or 2 for the SHOGUN. No diagonal moves, no jumping, no doubling
back, and at most one turn per move. Land on an enemy piece to capture it.

CONTROLS
Mouse:       click a piece, then click where to move it (click it again to cancel)
Keyboard:    arrow keys / WASD move the cursor, ENTER or SPACE selects
Controller:  d-pad / left stick moves, A selects, B or START pauses
ESC          pause (press again for the main menu); quits from the main menu
F11 / ALT+ENTER  window / fullscreen (web version: F)

The window can be resized freely. Text is pixel-perfect at 960x540, 1440x810,
1920x1080 (fullscreen on a 1080p screen), 2560x1440 and 4K.
On a phone the web version uses the original portrait layout - for two players,
lay the phone flat between you, one player at each end.

MENU OPTIONS
Show move guides     highlight the squares the selected piece can move to
Always show terrain  show every square's terrain value
Computer opponent    CLASSIC = the original 2013 AI, IMPROVED = harder
Settings are remembered (Windows: %APPDATA%\TCKSoft\shogun.cfg).
